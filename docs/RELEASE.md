This candidate adds optional local text recognition from plain PNG images on macOS. The host uses Vision's verified fast CPU English mode in a restricted worker, returning bounded text, confidence and region boxes. OCR can misread letters, punctuation and numbers; it does not attach an image to a chat or provide general image understanding.

The workspace suite passed **220 tests**, with **41 installed self-tests**. Packaged Native Messaging recognized the public W3C page label and 17 regions from a repository brief. Recognition errors are recorded rather than hidden. Stale hashes, private paths, hard links, malformed/oversized inputs and unsupported parameters were refused; worker tests prove denied user-file reads, writes and network connections. Doctor verified 20 matching audit entries.

Only fast CPU revision 1 English is exposed. Accurate Vision mode failed during the isolated probe; no unrestricted fallback was added. Other languages, rich image formats and Word rendering remain pending.

**Live Chrome acceptance is pending.** Source/package/manifest versions match 0.5.21; the normal Chrome bundle and installed host remain 0.5.7 because the current browser connection is unavailable. The physical older Intel Mac remains unverified.
