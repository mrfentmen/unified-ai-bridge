This candidate adds PDF embedded-text reading with physical page references and explicitly approved PNG page previews on macOS. Rust calls system PDFKit/CoreGraphics inside a disposable worker. The source hash and current permissions are rechecked before output; existing files are never overwritten. Network and unrelated file access are denied in the worker.

The workspace suite passed **181 tests**, and the isolated installed host passed **41 self-tests**. Six PDF integration tests cover text continuation, rotation and actual pixels, empty text pages, encryption/size/malformed failures, source preservation, denied or changed approvals and protected paths. A separate worker test exercises actual filesystem/network denials. Packaged Native Messaging extracted W3C's public PDF and saved a 707 × 1000 PNG that was visually inspected; doctor verified all 22 audit entries.

PDF previews omit annotations and interactive form appearances. Encryption, OCR, DOCX layout rendering and image delivery to a chat remain unavailable. Linux returns an explicit unsupported PDF result. Physical old Intel Mac compatibility remains a release check. The previous 0.5.14 Linux/Intel tests passed, confirming its job-test synchronization fix.

**Live Chrome acceptance is pending.** The candidate is packaged in isolation; the normal Chrome bundle and installed host remain 0.5.7 because browser automation is unavailable in this session.
