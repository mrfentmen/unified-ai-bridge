This candidate adds local PCM WAV inspection and reviewed trimming into a new file. The host reports sample rate, channels, bit depth, frame count, duration and hash. An approved trim copies exactly the selected interleaved frames and preserves the original. Unknown metadata, unsupported codecs, stale hashes, overwrites and protected destinations are refused.

The workspace suite passed **216 tests**, with **41 installed self-tests**. Seven new checks cover sample widths, padding, bounds and denial/race cases. Packaged Native Messaging trimmed a public SciPy sample to 400 stereo frames. Independent Python and macOS decoders reopened it; macOS afconvert produced exactly the expected signed samples. Doctor verified 51 matching audit entries.

The first subset supports ordinary mono/stereo integer PCM WAV up to 32 MiB and 30 minutes. It does not provide playback, transcription, resampling, video, compressed formats or chat audio delivery. A public sample with inconsistent length was correctly rejected; the verification script's expected error was corrected without weakening validation.

**Live Chrome acceptance is pending.** Source/package/manifest versions match 0.5.20, while normal Chrome and its installed host remain 0.5.7 because the current browser connection is unavailable.
