This candidate adds XLSX inspection, bounded typed cell reads and an approved editor for existing plain cells. Edits create a new workbook, preserve the original and selected styles, and verify untouched package payloads. Formula recalculation, tables, drawings, merges, protection and other unsupported editing features are refused explicitly.

The workspace suite passed **187 tests**, and the isolated installed host passed **41 self-tests**. Six workbook integration tests cover literal/cached values, Unicode and OOXML escapes, preservation, policy and stale approvals, hostile packages and bounded metadata. Packaged Native Messaging read a public workbook, denied an edit, then approved a new copy. Independent XML reads and macOS Quick Look confirmed the saved change; doctor verified all 24 audit entries.

The final source hash and current permissions are checked before create-only publication. The editor does not add missing cells, resize columns, replace originals or evaluate formulas. Reader caches can be absent or stale. PDF candidate 0.5.15 passed Linux tests, Intel tests and Intel packaging.

**Live Chrome acceptance is pending.** The candidate is packaged in isolation; the normal Chrome bundle and installed host remain 0.5.7 because browser automation is unavailable in this session.
