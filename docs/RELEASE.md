This candidate adds bounded public-page reads and file downloads. Network access starts off. The user grants exact public origins, then approves each anonymous GET. DNS addresses and redirects are checked, connections use pinned addresses, and downloads create new workspace files without overwriting or executing anything.

The workspace suite passed **202 tests**, and the isolated installed host passed **41 self-tests**. Eight dedicated checks cover destination restrictions, transport limits, pinned DNS, HTML extraction, approvals, revocation and workspace policy. Packaged Native Messaging fetched actual public HTML and saved W3C's sample PDF with a hash matching the earlier independent sample. Doctor verified all 41 audit entries.

The initial subset refuses private/local addresses, credentials, cookies, query strings, custom ports, compressed responses and automatic retries. Text output is static source extraction, not a rendered page. Transfers stop when their grant changes; a request already sent cannot be retracted. Authenticated AI-chat files still use the browser's selected-download importer.

**Live Chrome acceptance is pending.** Source/package versions match 0.5.18, but the normal Chrome bundle and installed host remain 0.5.7 because browser automation is unavailable. Network access remains disabled in the normal installation.
