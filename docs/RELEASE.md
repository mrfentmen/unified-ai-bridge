This candidate adds durable controls for a chat task's local tool calls. Pause/Stop block new and queued requests and close waiting approvals. Resume keeps the original remaining call budget. Task identity, state and receipts survive host restarts; rejected and uncertain calls never automatically rerun.

The workspace suite passed **194 tests**, and the isolated installed host passed **41 self-tests**. Six dedicated task checks plus a real framed integration test cover persistence, budgets, ownership, approval races and reports. Packaged Native Messaging created a file, recovered its exact saved result after restart, stopped an approval and reported a host-exit request as uncertain. Doctor verified all 27 audit entries.

The popup/side panel can inspect recent tasks and save private reports distinguishing completed, failed, denied, cancelled and unverified requests. Reports include bounded summaries, recovery/job IDs when present and audit links for newly finished calls. Already executing operations may finish; command jobs have separate Stop controls. This does not schedule whole tasks, restart a model or infer overall completion.

**Live Chrome acceptance is pending.** Source/package versions match 0.5.17, but the normal Chrome bundle and installed host remain 0.5.7 because browser automation is unavailable. The previous 0.5.16 candidate passed Linux tests, Intel macOS tests and Intel packaging.
