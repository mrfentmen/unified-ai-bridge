0.5.22 adds opt-in **YOLO mode** for routine local writes and fixes tabs retaining stale sessions after the native host restarts.

Choose a duration and automatic-approval cap in the popup or side panel. Text/code edits, write-only patches and supported output creation can run without repeated clicks. Stop restores normal permissions. Protected paths, file hashes, task budgets and narrower session grants remain enforced. Deletes, restores, network access, desktop control, integrations and Git commits keep their separate policies; commands retain their allowlist and approval settings. Restarting the host or changing workspace/policy turns YOLO off. It cannot dismiss macOS permission dialogs.

Live Chrome verification: ChatGPT created a Rust file through preview/apply/read-back with an audited automatic approval and returned results in the conversation. After Stop, an extension-control patch required approval; Deny created no file. Ten hidden tabs across all seven providers and both Grok sites recovered sessions after an idle host restart, without reloading or replaying writes. A queued result remained available. This is session-recovery evidence, not a new full tool acceptance pass for every provider.

Validation: **230 routine tests passed**, one previously verified long command test was not rerun, and **41 installed self-tests passed**. Dedicated coverage includes expiry, Stop, concurrent approval-cap reservations, workspace/restart isolation, narrower grants, stale hashes, traversal/private/research denials and framed request deduplication.

Still open: ChatGPT context-full delivery needs a specific message; Gemini setup drafts and Qwen foreground/candidate behavior can interrupt unattended work. Grok remains quota-blocked for remaining tests. Stable macOS signing/permission persistence, physical older Intel testing, image/file handoff, broader tool acceptance and whole-task scheduling remain unfinished.
